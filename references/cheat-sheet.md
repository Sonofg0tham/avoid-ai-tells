# Cheat Sheet: Tells to Fixes

One-page scan. Each row is a tell, what it looks like, and the move that fixes it. Use it as a final lint pass over a draft. Remember the cluster rule: one of these in isolation is usually fine, several together is the problem.

## High-value tells (check these first)

| Tell | Looks like | Fix |
|---|---|---|
| Negative parallelism | "not just X, it's Y", "not only... but also" | Collapse to a plain statement |
| Rule of three | "fast, simple, and powerful"; every list is 3 long | Use 2, 4, or 1 strong word |
| Em dash overuse | spaced — emphasis — everywhere | Comma, brackets, or full stop |
| Puffery / significance inflation | "marked a pivotal moment", "a testament to" | State the plain fact |
| -ing significance tail | "..., highlighting its importance" | Delete the trailing clause |
| Compulsive summary | "In conclusion", "Overall", "Ultimately" | Stop when you're done |
| Cursed vocabulary | delve, leverage, robust, seamless, vibrant | Plain word, or cut |
| Formatting overkill | bold on every term, bullets for prose | Write sentences; bold rarely |
| Conjunctive crutches | "Moreover", "Furthermore", "Additionally" | "and", "also", "but", or nothing |
| Uniform rhythm | every sentence the same length | Mix long and short; fragments allowed |
| No specifics, no stance | true of any topic, commits to nothing | Add a real number, example, or opinion; if you can't know it, a marked placeholder, never a plausible guess |

## Secondary tells

| Tell | Looks like | Fix |
|---|---|---|
| Promotional tone | "nestled in the heart of", "breathtaking" | Report, don't sell |
| False range | "from intimate gatherings to global movements" | Name the two things directly |
| Hedging / false balance | "some argue... while others contend" | Take a position |
| Vague attribution | "experts say", "studies show" | Name the source or drop it |
| Generic opening | "In today's fast-paced world" | Open on the actual point |
| Section-summary repetition | heading restated in the closing line | Say it once |
| Bold-lead bullets | "**Scalability:** It scales easily." | Drop the bold lead or add real info |
| Emoji in headings | 🚀 in an H2 | Remove unless the register calls for it |
| Hyphen for ranges | 1990-2000, 3-2 | En dash (–) if house style wants it |
| Stray markdown / quotes | leftover **, backticks, curly vs straight | Normalise to the destination |

## Chatbot residue (strip on sight)

Sycophantic openers ("Great question!", "Certainly!"), meta-commentary ("Here's a draft", "I hope this helps"), mid-text address ("As you requested"), placeholders ("[Company Name]"), and "As an AI language model". None of it belongs in published text.

## The one rule that overrides the table

Don't over-correct. If a fix makes the rhythm feel random, forces in detail that doesn't fit, or strips a word the sentence needs, undo it. The aim is writing that sounds like a specific person who knows the subject, not writing that passes a checklist.
